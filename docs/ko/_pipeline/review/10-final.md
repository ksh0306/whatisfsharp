  "상향 변환"이다. "캐스팅"·"하향 변환" 오용 없음.
- 코드 주석·출력 문자열의 한국어(정원, 상향 변환, 참조/구조적 동등성, 가변)는 본문 표기와 일치한다.

  시작해 바로 위 559줄 `// 1` 과 같은 열에 선다(전문가안 그대로 쓰면 맞는다). 555~558줄의
  주석 열(68·69열)은 원래 이 줄과 다르므로 건드리지 마라.

- [개선 권장 348줄] `// start: System.DateTime -> stepMinutes: float -> IClock` 로 교체하는 것이
  맞다. 독립 주석 줄이라 열 정렬 영향이 없다.

- [개선 권장 248줄] 전문가가 붙이라고 한 실측 한 절은 그대로 쓰면 문장이 길다. 용어집 표기에 맞춘
  수정형을 제시한다(`abstract class` 행의 근거와 같은 내용이다).
  수정형(248줄 끝에 이어 붙일 두 문장): "F# 인터페이스에는 기본 구현도 상태도 담을 수 없다. 인터페이스 선언에 `default` 를 붙이면 그 타입이 클래스가 되어 다른 타입에서 `interface ... with` 로 구현할 때 `error FS0887: 'IGreeter' 형식은 인터페이스 형식이 아닙니다.` 가 나고, 인터페이스 본문에 `let` 을 적으면 `error FS0963` 이다. 둘 중 하나라도 필요하면 추상 클래스로 간다."
