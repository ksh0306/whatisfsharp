# 07챕터 용어 후보 (F# 전문가 검수, 후보 모드)

`docs/ko/GLOSSARY.md` 는 편집하지 않았다(다른 챕터 전문가와 동시 작업 중).
아래 행을 알파벳 순 위치에 그대로 삽입하면 된다.

## 확정 제안 (그대로 삽입)

| 영어 | 한국어 표기 | 비고 |
|---|---|---|
| banana clips | 바나나 클립 | 액티브 패턴 이름을 감싸는 `(\|` `\|)` 괄호 짝. 원서 p.91 표기. 정착된 역어가 없어 음차한다. "바나나 괄호"·"바나나 클립스" 쓰지 않는다. 7챕터 |
| `Choice` | `Choice` | 번역하지 않는다. 다중 케이스 액티브 패턴의 실제 반환 타입. `FSharp.Core` 에 `Choice<'T1,'T2>` 부터 `Choice<'T1,...,'T7>` 까지만 있고(실측: `FSharpChoice`2`~`FSharpChoice`7`) 이것이 케이스 상한 7개의 근거다. 케이스 식별자는 `Choice1Of3` 꼴이다 |
| `enum` | 열거형 | MS ko 표기와 일치. `System.DayOfWeek` 같은 .NET 열거형. 선언된 이름 밖의 값도 담을 수 있어 이름을 다 적어도 빠짐없는 패턴 매칭으로 인정되지 않는다(경고 FS0104). 이 점이 판별 유니온과 다르다 |
| `MatchFailureException` | `MatchFailureException` | 번역하지 않는다. 빠짐없지 않은 `match` 식이 실행 시점에 어느 케이스에도 걸리지 않을 때 던지는 예외 |
| multi-case active pattern | 다중 케이스 액티브 패턴 | `(\|A\|B\|C\|)`. 실패하지 않으므로 `option` 을 쓰지 않고 `Choice<...>` 를 반환한다. 케이스는 7개까지다(오류 FS0265). 기확정 `case`→케이스 계열에 맞춰 "다중 사례" 쓰지 않는다. 문맥이 분명하면 "다중 케이스"로 줄여 쓴다 |
| parameterized partial active pattern | 매개변수 있는 부분 액티브 패턴 | `(\|Name\|_\|) arg`. MS 공식 한국어 F# 문서가 "매개 변수가 있는 활성 패턴"을 쓰므로 "매개변수 있는"이 MS 표기와 계열이 맞다. "매개변수화된"은 `-ized` 직역이라 채택하지 않는다. 문맥이 분명하면 "매개변수 있는 부분"으로 줄여 쓴다. 검사할 값이 항상 마지막 매개변수다. 8챕터가 이 표기를 쓴다 |
| partial active pattern | 부분 액티브 패턴 | `(\|Name\|_\|)`. 이름 마지막 자리의 와일드카드가 "입력 중 일부만 걸린다"는 뜻이고, 부분 적용(partial application)과는 아무 관계가 없다. 기본형은 `option` 을 반환하고, F# 6 이후 `[<return: Struct>]` 로 `voption`, F# 9 이후 `bool` 도 반환할 수 있다 |
| pattern combinator | 패턴 조합 연산자 | 패턴 자리의 `&`(둘 다 만족)와 `\|`(하나라도 만족). 부정 조합자는 없다. MS ko 는 개별 이름으로 "AND 패턴"/"OR 패턴"을 쓰나 기확정 "AND 타입"/"OR 타입"과 층위가 달라 헷갈리므로 노트는 두 연산자를 묶어 "패턴 조합 연산자"로 부른다. `\|` 패턴은 양쪽이 같은 변수 집합을 바인딩해야 한다(오류 FS0018) |
| single-case active pattern | 단일 케이스 액티브 패턴 | `(\|Name\|)`. 실패하지 않고 변환 결과 타입을 그대로 반환한다. 판정이 아니라 변환에 쓴다. 매개변수를 붙일 수 있다(`(\|RoundedTo\|) : int -> float -> float`) |
| struct representation | 구조체 표현 | 액티브 패턴에 `[<return: Struct>]` 를 붙여 반환 타입을 `option` 에서 `voption` 으로 바꾸는 것. FSI 한국어 메시지 표기가 "활성 패턴에 대한 구조체 표현"이다. F# 6 이후 쓸 수 있다(F# 5.0 에서는 오류 FS3350) |
| `voption` | `voption` | 번역하지 않는다. `Option` 의 구조체판이고 정식 이름은 `ValueOption`. 케이스 식별자는 `ValueSome`/`ValueNone`. 힙 할당이 없다 |

## 기확정 변경 제안 (적용하지 말고 사람이 판단할 것)

| 영어 | 한국어 표기 | 비고 |
|---|---|---|
| active pattern | 액티브 패턴 | [기확정 변경 제안] 표기 자체는 그대로 두고 비고 마지막 문장만 고칠 것을 제안한다. 현재 비고는 "부분 액티브 패턴은 `option` 을 반환한다"로 단정하는데, 실측으로 F# 6 이후 `[<return: Struct>]` 를 붙이면 `voption`, F# 9 이후 본문이 `bool` 이어도 통과한다(각각 langversion 5.0/8.0 에서 오류 FS3350 으로 막힌다). 7챕터 본문이 두 형태를 다 다루므로 용어집 비고와 어긋난다. 제안: "부분 액티브 패턴은 `option` 을 반환한다(F# 6 이후 `voption`, F# 9 이후 `bool` 도 가능)." 표기를 바꾸는 제안이 아니므로 앞 챕터 본문 수정은 필요하지 않다 |

## 검토했으나 등재하지 않은 것

- `active recognizer` — F# 명세 용어이나 원서와 노트 어디에도 나오지 않는다.
- `partial` 단독 — `partial active pattern` 항목의 비고에서 부분 적용과의 혼동을 막는 것으로 충분하다.
- `full active pattern` — FS3872 영문 메시지에만 나오는 표현이다. 노트는 "다중 케이스"·"단일 케이스"로 나눠 부르므로 별도 표기가 필요하지 않다.
