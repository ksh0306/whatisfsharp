## 검증 방법 (에이전트 보고를 그대로 믿지 말고 직접 돌릴 것)


인자 없이 돌리면 `docs/ko/*.md` 전체를 본다. `KEEP=1` 은 추출 스크립트 경로를 알려 준다.

**직접 grep 을 짜지 마라** — 검사식이 갈라지면 게이트를 신뢰할 수 없다.

원문이 없으면 먼저 만든다(`.cache/` 는 git 추적 밖이다):

## 남은 판단거리 (사람이 정할 자리)

용어집 마무리 보고서(`review/glossary-final.md`) 4.2 에 있다. 급하지 않다.
- **`Map` 행이 "사전" 을 금지하는데 14장이 `ConcurrentDictionary` 를 6곳에서 "사전" 이라 부른다.**
  같은 문서에 `Map` 도 나온다. 되돌리려면 노트 수정이 따라온다.
- **`next steps` 행이 "다음 단계" 를 금지하는데 03·09장이 일반 명사로 쓴다.**
둘 다 표기는 그대로 두고 예외 범위만 비고에 적어 둔 상태다.

## 지금까지 세운 결정 (다시 논의하지 말 것)

- **코드는 노트 안에 펜스 블록으로 둔다.** 별도 `.fsx` 를 만들지 않는다.
  실행 단위는 ```` ```fsharp id=<NN>-<주제> ````, **같은 `id` 는 문서 순서대로 이어붙여 실행된다.**
  `id` 없는 블록은 실행하지 않는다(시그니처 조각, 컴파일 오류 예시, NuGet·`namespace` 때문에
  스크립트로 못 도는 코드).
  → 타입·모듈 선언을 같은 단위의 여러 블록에 중복하면 `FS0037` 로 실패한다.
- **원서의 버전 서술을 그대로 옮기지 마라.** `--langversion` 으로 실측하고 "F# N 부터" 로 적는다.
- **컴파일러·FSI 메시지 인용은 원문 표기를 유지한다.** 게이트의 문체·번역체 검사가 인라인 백틱을
  면제한다(펜스 블록은 아니다).
- **병기는 챕터마다 1회까지 허용한다**(독자가 중간 챕터부터 읽을 수 있으므로).
- **날짜·시간을 문자열로 바꿀 때 `CultureInfo.InvariantCulture` 를 넘긴다.**
  로캘에 따라 달력(불교력 등)과 구분 기호가 갈린다.
- **문자열 보간·`%s` 뒤에 조사를 붙이지 마라.** 값의 받침을 알 수 없다. 값을 문장 끝에 둔다.
- **`N챕터` 로 부른다.** 본문에 노트 파일 이름을 적지 않는다. 서문은 `서문 챕터`,
  원서 서문을 가리킬 때는 `원서 서문`.
- **확인할 수 없는 "처음" 주장은 걷는다.** 뒤 챕터를 전수 확인해야 참이 되는 종류다.
- **지시서의 줄 번호를 좌표로 쓰지 마라.** 내용을 확인하고 유일한 문자열로 치환하라.
- **집필은 두 개씩** 나눠 돌리는 편이 안전하다. 검수는 병렬로 무리 없다.
- **병렬 집필 후 도메인 겹침을 점검하라.** 동시 집필 중인 챕터는 서로를 알 수 없다.

## 파이프라인이 실제로 잡아낸 것 (검수 계층을 유지할 근거)

- **원서 오기·오류 20건 이상.** 따라 하면 막히거나 값이 어긋나는 것들 —
  `open FsUnit` 이 xUnit 에서 안 되는 것, `Update` 의 `KeyNotFoundException`,
  괄호 누락으로 컴파일 안 되는 코드, `items.Capacity` 정원 판정, 원서가 자기 자신과 어긋나는 자리.
- **원서를 충실히 옮기다 F# 에서 성립하지 않게 된 서술 다수** —
  `|>` 의 "접두 형태", 값 제한 조건 역방향(두 챕터), `and!` 를 "나란히 실행" 으로 설명.
- **결론은 맞고 근거가 틀린 유형**이 배치 C·D 에서 반복됐다. 학습 노트에서는 근거가 결론만큼 중요하다.
- **최종 검수가 전문가 지시서 자체에서 100건 이상**을 잡았다(용어집 위반, 문서 관례, 파급 미추적,
  줄 번호 오류, 서로 충돌하는 지시).
- **병합자가 만든 코드·문면에서도 오류가 나왔다** — 조사 버그, `200쪽 남짓`(뜻이 반대),
  병기 중복, 선행어 없는 지시.
- **집필자가 검수 지시를 실측으로 뒤집은 사례 다수.** 실측이 최종 방어선이다.
- **뒤 배치가 앞 챕터의 오류를 드러낸다.** 문화권 버그는 10장까지, 색인은 13장까지,
  `header row` 는 06·11장까지 거슬러 올라갔다. **새 규칙을 세우면 앞 챕터를 훑어라.**
